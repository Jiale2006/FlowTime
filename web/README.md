# FlowTime Metrics · 主题仪表卡

22 个细项的量化视图，分 10 组。产出两种形态：

| 形态 | 路径 | 用途 |
|---|---|---|
| **单文件 SVG** | `svg/*.svg` | 自包含，双击即开，可直接嵌入 App / 文档 |
| **画廊页** | `web/index.html` | 展示用，带入场动效、悬停反馈、跑马灯 |

## 设计方向（Design Direction）

- **受众**：自己用的时间统计可视化；也作为项目视觉规范的样板
- **调性**：**工业实用 Industrial / Utilitarian** —— 发丝线、等宽数字、仪表盘密度、状态色体系
- **记忆点**：**四角括号 + 发丝网格 + 等宽读数** —— 像一块真实的工业仪表面板
- **字体**：画廊页用 **Space Mono（展示 / 数字）+ IBM Plex Sans（正文）**；
  SVG 内退回系统等宽族（`SF Mono / Consolas / ui-monospace`），保证离线自包含
- **配色**：暖近黑底 `#141210` + 卡片 `#1c1917`，**唯一强调色 = 琥珀 `#ff8a3d`**；
  16 个主题各带状态色，**仅作数据编码，不作装饰**

### 关于「多彩配色」（对 skill 纪律的说明）

skill 要求「单屏不超过 1 个强调色」。本设计中：
- **UI 层**（版头、表格、跑马灯、悬停、焦点）严格只用**琥珀一个强调色**
- 16 个主题色属于**数据编码维度**（categorical color scale），
  用于区分数据类别，与「装饰性强调色」不同性质 —— 这是工业仪表盘的常规做法
  （思科 / Grafana / 电力 SCADA 都如此）

## 设计令牌

见 `web/styles/tokens.css`。核心：

```
--bg:#141210  --surface:#1c1917  --text:#f4efe7  --muted:#8b8375
--accent:#ff8a3d    /* 唯一强调色 */
--hair:rgba(244,239,231,0.13)      /* 发丝线 */
--font-display:"Space Mono"  --font-body:"IBM Plex Sans"
--fs-display:96px  字距 -0.03em
--ease-out:cubic-bezier(0.16,1,0.3,1)   --dur-base:320ms  --dur-slow:640ms
```

## 动效规格

| 类型 | 实现 |
|---|---|
| 入场序列 | 首屏版头 4 组错峰 90ms；卡片按所在分组错峰 80ms × 4 循环 |
| 滚动触发 | `IntersectionObserver`，只动 `opacity` / `translateY(26px)` |
| 悬停 | 上浮 4px + 边框转琥珀 + 琥珀光晕阴影 + 115° 扫光扫过 |
| 跑马灯 | 42s 线性循环，悬停暂停 |
| 降级 | `prefers-reduced-motion: reduce` 下全关；**JS 未就绪时内容默认可见**（渐进增强） |

## 运行

直接双击 `web/index.html`（file:// 可用，字体走网络降级到系统等宽）。
或起本地服务：

```bash
cd web && python -m http.server 8791
# → http://127.0.0.1:8791
```

## 重新生成

```bash
python _gen_cards.py     # 22 张 SVG → svg/
python _gen_gallery.py   # 画廊页 → web/index.html
```

两个脚本都是纯 Python 标准库，无外部依赖。改 `_gen_cards.py` 里的 `CARDS` 列表即可增删主题。
